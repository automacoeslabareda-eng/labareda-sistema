# Shared — Codigo e Configuracoes Compartilhadas

Componentes reutilizados entre modulos, sem compartilhar dados entre propriedades.

## Conteudo

```
shared/
├── supabase/    # Tipos, helpers e config base do Supabase
└── utils/       # Utilitarios comuns (formatacao, validacao, etc.)
```

## Principio

- Codigo e padroes: COMPARTILHADOS
- Dados entre propriedades: NUNCA compartilhados (Labareda e Sao Miguel sao isolados)
