# Modulo 2 — E-commerce Sob Medida + Automacao

**Objetivo:** Loja online propria da marca, com automacao completa que transforma cada venda em um fluxo operacional reportado pelo Telegram.

**Status:** Onda 2 (pendente)

## Loja Sob Medida

- Loja online com codigo e design proprios (vestuario, chocolates, artes, cosmeticos)
- Catalogo de produtos, carrinho, checkout 3 passos com cadastro rapido
- Pagamento via Mercado Pago
- Etiqueta de envio via Mercado Pago
- Frete fixo pre-configurado (tabela do cliente)

## Automacao Pos-Venda

- Comprovante de venda + NFSe (Mercado Pago)
- Preparacao de etiqueta/frete
- Baixa automatica no estoque
- Alerta estoque < 5 unidades
- Aviso no Telegram (cliente, produto, valor)

## Referencias Visuais

- misci.com — moda premium, layout limpo
- sometimesalways.com.au — estilo artesanal/boutique
- dianasseafood.com — editorial, produtos
