# Estoque Labareda - Dimensoes para Calculo de Frete

> Dimensoes pesquisadas com base em embalagens padrao do mercado brasileiro.
> Valores sao estimativas para produtos artesanais - recomenda-se conferir com regua/fita metrica os produtos reais antes de cadastrar no sistema de frete.
> Dimensoes = embalagem pronta para envio (produto + embalagem de protecao)

## COSMETICOS

### Creme - Para Todo o Corpo 180ml
- **Peso:** 360g
- **Dimensoes estimadas (embalagem):** 18 x 7 x 7 cm (C x L x A)
- **Tipo embalagem sugerida:** Caixa de papelao com protecao interna
- **Nota:** Bisnaga/pote 180ml tipicamente tem ~6-7cm de diametro. Com caixa + protecao, considerar 18x7x7cm

### Pos-Bite roll-on 10ml
- **Peso:** 70g
- **Dimensoes estimadas (embalagem):** 12 x 5 x 5 cm (C x L x A)
- **Tipo embalagem sugerida:** Caixa pequena com protecao
- **Nota:** Frasco roll-on 10ml padrao: ~2.5cm diametro x 8.5cm altura. Embalado em caixinha com protecao

### Desodorante 40ml
- **Peso:** 122g
- **Dimensoes estimadas (embalagem):** 10 x 7 x 7 cm (C x L x A)
- **Tipo embalagem sugerida:** Caixa pequena com protecao
- **Nota:** Pote 40ml padrao: ~4.5cm diametro x 4.3cm altura. Com caixa + protecao

## NOTAS IMPORTANTES

1. **Valores sao ESTIMATIVAS** baseadas em pesquisa de mercado para produtos similares. Recomenda-se medir e pesar os produtos reais com embalagem para valores exatos.

2. **Peso cubado vs peso real:** Transportadoras usam o MAIOR entre peso real e peso cubado. Formula peso cubado: (C x L x A) / 6000 (em cm, resultado em kg).

3. **Dimensoes minimas Correios:** 16 x 11 x 2 cm (PAC/SEDEX). Nenhum produto esta abaixo.

4. **Dimensoes maximas Correios:** 100 x 100 x 100 cm, soma das dimensoes <= 200cm. Todos os produtos estao dentro dos limites.

5. **Para as obras de arte:** O tubo postal e mais economico no frete pois tem menor peso cubado. Porem, para obras de alto valor, a caixa plana oferece melhor protecao.

6. **SuperFrete:** Ao cadastrar os produtos no sistema de frete, usar os valores da tabela resumo acima. Os pesos ja incluem embalagem.
